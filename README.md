# Plataforma de Gestão e Monitoramento Hídrico

Aplicação responsiva para acompanhar consumo de água, sensores e alertas de desperdício em uma instituição pública ou escola.

## Development

Você precisa do Node.js e do npm para executar o projeto localmente.

```sh
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
